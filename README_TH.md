# V80 Glass — สร้างใหม่ 7 สไลด์

โครงการใหม่แยกจากงานเดิม ไม่โหลดโมเดล Three.js หรือ CSS phone เดิม ภาพโทรศัพท์ใช้ PNG ทั้งสามสีที่ผู้ใช้แนบ

## เปิดบน Termux
```bash
python serve.py
```
เปิด URL ที่โปรแกรมแสดง โปรแกรมเลือกพอร์ตว่างอัตโนมัติ เปลี่ยนเป็นพอร์ตคงที่ได้ด้วย `python serve.py --port 8080` ผู้ใช้ไม่ต้องติดตั้ง npm บนมือถือ มี dist พร้อมใช้

## การควบคุม
- ปุ่มเริ่ม / ลูกศร / จุดนำทาง / สารบัญ เพื่อเลือกสไลด์เอง ไม่มี autoplay สไลด์หรือการเปลี่ยนสี
- ปัดแนวนอนบนพื้นที่ว่างเพื่อเปลี่ยนสไลด์ หรือใช้ ArrowLeft/ArrowRight เมื่อโฟกัสพื้นที่สไลด์
- ดีไซน์: กดเลือกสีเพื่อขยาย แล้วเลือกม่วง เขียว หรือดำ มี crossfade
- กล้อง: เลือกแท็บที่มี MP ไม่มีจุดระบุเลนส์บนภาพ แล้วกดปุ่มทดลอง OIS / เทียบ Software กับ Optical Zoom ที่ 3× แบบครึ่งจอ / มุมกว้าง
- Processor: เลือกเล่นเกม ดูหนัง LINE ถ่ายภาพ เพื่อให้ส่วนที่เกี่ยวข้องเรืองแสง
- Memory: แตะ 4 แอปเพื่อเติม RAM แล้วแตะแอปถัดไปจะขึ้น Full เปิด 8+8 เพื่อเพิ่มอีก 4 ช่อง แถบสีเข้มใน Storage คือพื้นที่ที่กันไว้
- Display: ฉาก Memory ถูกย่อพร้อม fade และกรอบโทรศัพท์หุบเข้ามา มีแท็บสเปกจอ / เทียบ FPS / ความลึกสี (bit) ความละเอียดในสเปกยังแสดง (1.5K) เปรียบเทียบ 30 กับ 60/120/144 FPS ด้วยปุ่มเริ่ม/หยุด และเทียบขั้นสี 6/8/10-bit ได้
- Battery: ปุ่มเสียบชาร์จเริ่มภาพสาธิต กดอีกครั้งเพื่อหยุด

## ภาพและข้อมูล
ไฟล์ภาพ: public/assets/{purple,green,black}.png เป็นภาพผู้ใช้แนบ เก็บต้นฉบับไว้ครบ แสดงและซูมด้วย CSS ไม่สร้างภาพตัวเครื่องใหม่
V80 หน้าแรกเป็น SVG ลายเส้นวาดใหม่ตามสไตล์ที่ขอ ไม่ได้แนบฟอนต์ vivo ทางการ
สเปกกล้อง จอ แบตเตอรี่ ใช้ vivo IN เป็นฐาน มีป้ายระบุในหน้าและที่มา ต้องตรวจ SKU ไทยก่อนใช้ยืนยันการขาย
Snapdragon อ้างอิง Qualcomm: 1 Prime สูงสุด 2.8 GHz, 4 Performance สูงสุด 2.4 GHz, 3 Efficiency สูงสุด 1.8 GHz มี Adreno GPU, Hexagon NPU, Spectra ISP
ภาพเรืองแสงเป็นแผนผังเชิงแนวคิด การเลือกคอร์ไม่ได้ล็อกตามประเภทแอป และวิดีโอมีตัวถอดรหัสเฉพาะ
Memory จำลอง 4/8 ช่องเพื่ออธิบาย 8/8+8 GB ไม่ใช่ผลวัดจำนวนแอปจริง RAM เสมือนใช้ Storage และช้ากว่า RAM จริง ไม่รับประกันความเร็วหรือจำนวนแอปสองเท่า

## ไลบรารีและ fallback
- ใช้ @shadergradient/react จริงสำหรับพื้นหลังบน WebGL2 สีม่วง/ชมพู ความเร็วต่ำ เพิ่ม glitter ด้วย CSS
- Liquid Glass JS ต้นฉบับอยู่ public/vendor พร้อม MIT license ใช้ปุ่มเริ่มที่เรนเดอร์ WebGL เมื่อรองรับ ส่วน UI อื่นใช้ CSS glass ในภาษาภาพเดียวกัน
- Cloud Browser นี้ปิด WebGL จึงตรวจได้เฉพาะ CSS gradient/glass fallback ต้องตรวจ ShaderGradient และปุ่ม refraction จริงบนอุปกรณ์ที่รองรับเพิ่มเติม
- ฟอนต์ไทย bundle จาก @fontsource/noto-sans-thai ไม่พึ่ง Google Fonts runtime
- โค้ดที่ใช้วาดฉาก/สาธิตเป็น HTML CSS SVG + React และ Web Animations API ไม่โหลดโมเดล 3D

## แก้และ build
```bash
npm ci
npm run build
```
แก้ข้อความ/ปุ่ม/ภาพสาธิตใน src/main.jsx ธีมใน src/style.css พื้นหลังใน src/background.jsx แก้เสร็จ build แล้วส่ง dist ทุกครั้ง

## อัปเดต 1.1
ภาพดีไซน์ใช้ SVG geometry mask แสดงเฉพาะโทรศัพท์ทั้งสามชิ้น พื้นขาวถูกซ่อนจริง ไม่ใช้ multiply จึงไม่ทำให้สีเครื่องหม่น ต้นฉบับ PNG ไม่ถูกแก้ไข
ภาพเปรียบเทียบซูมและความละเอียดวาดใหม่ด้วย Canvas (src/compare.jsx) การจำลองซอฟต์แวร์ซูมใช้ตัวอย่างภาพที่มีจำนวนพิกเซลน้อยกว่า ก่อนครอปขยายที่มุมเท่ากัน ไม่ใช่ผลถ่ายจริง
FPS ใช้เวลาของ requestAnimationFrame แล้ว quantize ตำแหน่งตามอัตราที่เลือก อัตราภาพที่เห็นจริงยังจำกัดด้วยจอและเบราว์เซอร์

## อัปเดต 1.2
ใช้ public/assets/black-v2.png และ green-v2.png จาก ImageGen ตามตัวเครื่องอ้างอิงใหม่ที่ผู้ใช้อนุมัติแล้ว พื้นหลังมี alpha จริง ไม่ใช้ mask ของรูปเก่า ภาพสีม่วงคงเดิม
Telephoto ค่อย ๆ ซูม 1× ↔ 3× ใน 1 วินาที ทั้งสองครึ่งใช้ตำแหน่งซูมเดียวกัน ย้อนทิศระหว่างเล่นได้ รองรับ reduced motion และยกเลิก RAF เมื่อออกจากฉาก แคชภาพต้นทางเพื่อไม่วาดฉากใหม่ทุกเฟรม

## อัปเดต 1.3 — ความลึกสี
ถอดตัวเปรียบเทียบความละเอียดออกจากหน้า Display เปลี่ยนเป็น src/bit-depth.jsx: เลือก 6↔8 หรือ 8↔10 bit ต่อช่อง R/G/B แสดง 64/256/1024 ระดับต่อช่อง และจำนวนสี RGB รวม เปลี่ยนสีม่วง/เทา และช่วงเต็ม/ขยายขั้นสีได้
โหมดขยายแสดงจำนวนขั้นในช่วง 1/16 เป็นแผนผังขยายเพื่อเห็น banding ไม่ใช่การส่งสี 10-bit จริงผ่าน Canvas ไม่มีการอ้างสเปก native bit depth ของ V80 ความลึกสีต่างจาก gamut และความละเอียดพิกเซล

## อัปเดตการควบคุมและปุ่มเริ่ม
กด Space bar บนพื้นที่สไลด์เพื่อไปหน้าถัดไป หน้าสุดท้ายไม่วนกลับ เมื่อโฟกัสอยู่บนปุ่มหรือเปิดสารบัญ/ข้อมูลอ้างอิง ปุ่มลัดจะไม่เปลี่ยนสไลด์ กดค้างไม่ข้ามหลายหน้า
ปุ่มเริ่มใช้ CSS ระหว่างเตรียมภาพกระจก เปิด WebGL เฉพาะเมื่อมีเฟรมที่ไม่ดำ และกลับ CSS เมื่อ context หาย ภาพสำหรับ refraction ใช้พื้นหลัง CSS แทนการคัดลอก WebGL canvas
